VS Code 入門三小時

從零安裝到能寫、能跑、能用終端機與 Git，最後做一張自己的個人名片網頁。適合完全沒寫過程式的學員。

⬇ 下載課程資料夾 (.zip)

解壓縮後用 VS Code「開啟資料夾」打開，今天全程就在這裡操作。內含： 課程PPT.pptx、練習.txt、上課用ppt.pptx、 名片模板 card-template.html、終端機小遊戲範例 game.py（及完整版 game-extended.py）。
