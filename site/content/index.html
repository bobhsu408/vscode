VS Code 入門三小時

從零安裝到能寫、能跑、能用終端機與 Git，最後做一張自己的個人名片網頁。適合完全沒寫過程式的學員，全程以「先操作、再解釋」為主——安裝後先動手開檔案、換主題，累積成就感後才進入介面理論。

時長約 3 小時（含休息） 對象有基礎電腦操作，未寫過程式 環境Python + 瀏覽器 形式投影 + 現場跟做
⬇ 下載課程資料夾 (.zip)

解壓縮後用 VS Code「開啟資料夾」打開，今天全程就在這裡操作。內含： 課程PPT.pptx、練習.txt、上課用ppt.pptx、 名片模板 card-template.html、終端機小遊戲範例 game.py（及完整版 game-extended.py）。

安裝與初次啟動

下載與安裝

前往官方網站下載對應作業系統版本（Windows / macOS）。強調：這是「編輯器」不是「作業系統」，也不是瀏覽器。

  • Windows：下載 .exe，安裝時建議勾選「加入右鍵選單」「加入 PATH」
  • macOS：下載 .zip，解壓縮後拖入應用程式資料夾
  • 常見卡點：學校/公司電腦沒有系統管理員權限 → 使用者層級安裝版
現場提示 安裝過程請學員全程跟做，不要用投影帶過——這一步最容易個別卡住，寧可多留時間巡場。

初次啟動一覽

開啟後先讓學員看一眼畫面即可，不深入解釋——語言暫時保持英文，介面認識與中文化留到後面模組再處理。先示範一次 Ctrl+Shift+P（Mac 為 Cmd+Shift+P）開啟命令面板，讓學員有印象即可。

檔案與專案管理：實際打開文件

「開啟資料夾」＝ VS Code 裡的「專案」

這是本模組最重要的觀念：VS Code 沒有「新建專案」按鈕，一個資料夾就是一個專案。直接用學員自己的下載資料夾練習，比新建空資料夾更有感。

  • File → Open Folder，選取「下載」資料夾（課程講義 PPT / 文件已預先放在裡面）
  • 左側 Explorer 會顯示該資料夾內容——第一次看到「一堆檔案變成可操作的樹狀清單」

用 Office 擴充套件直接在 VS Code 裡看 PPT / Word

安裝 Office Viewer 類擴充套件（Extensions 面板搜尋安裝），在編輯區直接點開下載資料夾裡的 .pptx / .docx 檔案。

  • 點開課程講義 PPT，示範可以直接在分頁裡翻頁預覽，不需要另外開 PowerPoint
  • 順便示範開啟一個 .docx 講義文件比對
  • 體會 VS Code 不只能寫程式，也能當「輕量文件檢視器」使用
帶學員做 請每個人自己在下載資料夾裡找到今天的講義檔案並點開看一次，建立「VS Code 也能看我平常的檔案」的直覺。

建立、儲存檔案（小練習）

  • 右鍵 Explorer 空白處 → New File，練習新建一個空白 .txt
  • 存檔快捷鍵 Ctrl+S；分頁上有圓點代表尚未儲存
常見誤解 很多初學者以為要「儲存專案」，其實 VS Code 沒有專案檔——存的永遠是個別檔案，資料夾只是視窗顯示範圍。

換主題、換字型 —— 讓 VS Code 變成自己的樣子

切換色彩主題

  • 命令面板 → Preferences: Color Theme，用方向鍵即時預覽並選定
  • 命令面板 → Preferences: File Icon Theme 切換檔案圖示風格
  • 可額外安裝主題套件（如 One Dark Pro）擴充選擇
帶學員做 讓每個人選一個自己喜歡的主題——這是本階段最能讓學員「有成就感」的一步，鼓勵他們現場分享畫面，順便再次練習命令面板的用法。

調整字型大小與字體

  • 設定 → 搜尋 font size 調整編輯字型大小
  • 設定 → 搜尋 font family 調整字體
  • 示範放大字型對長時間閱讀程式碼的幫助

繁體中文化（可選）

依個人習慣決定是否切換

介面已經玩過一輪、也換好喜歡的顏色，現在請學員自行決定：習慣英文介面就跳過這一步，想要中文介面的人再一起做。

  • 命令面板輸入 Configure Display Language
  • 安裝 Chinese (Traditional) Language Pack，重新啟動生效
教學用意 不強制統一語言——之後投影示範一律用中文介面講解，但學員自己的機器保留英文也完全沒問題，兩種都能對應到同樣的操作。

介面認識

五大分區導覽

前面幾個模組已經摸過 Explorer、命令面板、主題設定——現在正式把這些操作「掛回」對應的介面分區名稱，用「房間」比喻整個介面：

  • Activity Bar（左側最窄那排圖示）：切換不同功能面板的按鈕
  • 側邊欄（Side Bar）：檔案總管、搜尋、原始碼控制、擴充套件——剛才開資料夾、裝 Office 套件都在這裡操作
  • 編輯區：真正打字寫東西、剛才看 PPT 的地方，可分割成多個分頁/多個窗格
  • 狀態列（底部）：目前語言、編碼、游標位置、Git 分支
  • 右上角工具列：分割編輯器、開啟終端機、切換版面配置

最上方選單列（File / Edit / View…）

視窗最上方一整排文字（File、Edit、Selection、View、Go、Run…）是傳統選單，跟命令面板是兩條通往同樣功能的路——初學者常常忽略它，但它更適合「用滑鼠慢慢找」的習慣。

  • File：Open Folder、Save、Save As，就是剛才開下載資料夾的另一條路
  • View：開啟 Explorer、Terminal、Extensions 等各面板，跟 Activity Bar 是同一批功能的另一個入口
  • Run：執行目前開啟的檔案，等一下寫小程式時也可以從這裡跑，而不只是打終端機指令
視窗變窄時 當視窗或畫面解析度較小，選單列會摺疊成一個「⋯」（More Actions）圖示，把 Terminal、Help 等選項收進去——提醒學員別以為選單不見了，點開「⋯」就找得到。

擴充套件：安裝 Python

安裝擴充套件

主題、字型、（可選的）中文包已經在課程一開頭裝過了，這裡只需要補裝實作要用的 Python 套件。

  • Activity Bar 中方塊圖示 → Extensions
  • 安裝 Python（Microsoft 官方）：等下要寫一支小程式來執行
  • 示範停用 / 解除安裝套件的差異

終端機、寫一支程式執行、Git 基礎

內建終端機

Ctrl+` 開啟整合終端機——它就是在目前資料夾底下開的一個命令列。

python --version cd Desktop/vscode-workshop dir # macOS 用 ls
常見卡點 Windows 上 python 指令可能要打成 py；macOS 上可能要打 python3。上課前務必實測學員機型。

寫一支程式並執行

讓學員第一次體驗「我寫的東西跑起來了」。程式要短到每個人都能跟著打完，而不是看老師打字。新建 game.py：

import random a = random.randint(1, 50) b = random.randint(1, 50) print(f"{a} + {b} = ?") answer = int(input("你的答案：")) if answer == a + b: print("答對了！🎉") else: print(f"答錯囉～ 正確答案是 {a + b}")

終端機執行：

python game.py
帶學員做 請每個人自己跑一次，答對答錯都好——重點是看到程式有回應。行有餘力的學員可以看 game-extended.py（五題、四則運算、成績結算的完整版），但不要求當場打完。
備援 課程資料夾裡已經附了一份 game.py（跟這裡一樣）和 game-extended.py——手打卡住、或想直接看能跑的成品，隨時可以打開資料夾裡現成的這兩份。

Git 基礎操作

  • 終端機輸入 git init 初始化版本控制
  • 編輯檔案後，左側 Activity Bar 的「原始碼控制」圖示會出現變更數量
  • 在訊息框輸入說明文字，按 Ctrl+Enter 完成 commit
教學用意 不深入教 Git 指令，只讓學員知道「存檔的存檔」這個概念存在，之後有需要能自己延伸學習。

實作：做一張自己的個人名片網頁

這一段的設計原則 把今天學過的技巧（新建檔案、存檔、多游標、搜尋取代）一次用在同一個檔案上，最後在瀏覽器看到自己的成果。不需要網路、不需要安裝任何東西——刻意設計成不可能失敗，因為它是學員帶走的最後印象。

找到模板，另存成 card.html

  • 回到一開始打開的課程資料夾，裡面有一個 card-template.html
  • 點開它，另存新檔（Ctrl+Shift+S）成 card.html，之後就改這一份
帶學員做 打開 card.html 後留意分頁沒有圓點——代表這是已經存好的檔案，可以直接開始改。

先看一眼成品，再開始改

Explorer 對 card.html 右鍵 → Reveal in File Explorer / Finder，用瀏覽器打開它。

教學用意 先看到「這是一張真的名片」，學員才知道自己在改什麼。照「先操作、再解釋」的原則，這時候不要先講 HTML 是什麼。

三個編輯技巧，一次用上

  • Ctrl+D 換名字（3 分鐘）：游標點在任一個 你的名字 上，連按選起全部 3 處，直接打自己的名字。順手把 .avatar 裡的「名」改成自己姓名的第一個字。按過頭就 Ctrl+U 退回
  • Alt+點擊 改三個技能（2 分鐘）：按住 Alt（Mac：Option）依序點在三個技能標籤上，三個游標同時打字
  • Ctrl+H 換主題色（3 分鐘）：找 #3D5A80（連 # 一起輸入），確認「找到 5 筆」後全部取代。模板註解裡有四組建議色
常見誤解 多游標不是「複製貼上三次」，是三個游標同時打同樣的字；要打不一樣的內容就得一個一個改——這正是它的限制。
帶教技巧 換色這步呼應 00:45——「剛才你換的是 VS Code 的顏色，現在換的是自己作品的顏色。」

填完欄位，回瀏覽器看成果

自我介紹、身分、Email、城市直接打字改，Ctrl+S 存檔，切回瀏覽器按 F5 重新整理。

帶學員做 鼓勵學員轉螢幕給旁邊的人看，比照換主題那段的分享節奏。

收尾一句話：你剛剛不是「學會寫網頁」，是學會了用 VS Code 快速改一份檔案——這件事對任何檔案都適用。

排除狀況 中文亂碼：確認模板的 <meta charset="utf-8"> 還在，狀態列右下角應顯示 UTF-8（回扣模組 5「狀態列＝儀表板」）。瀏覽器不開 file://：把檔案拖進已開啟的瀏覽器視窗，或右鍵 Copy Path 貼到網址列。改壞版面：Ctrl+Z 可救，重新下載 zip 也能拿回原始檔。zip 打不開 / 找不到下載：直接看下方「模板原始碼」，整段選取複製貼上也可以。

  • 能切換喜歡的色彩主題與字型，依個人習慣決定是否切換為繁體中文
  • 能講出五大介面分區與選單列的用途，並用命令面板找到任何功能
  • 能安裝擴充套件（Python）並開啟整合終端機執行基本指令
  • 能寫出一支簡單的 Python 程式並在終端機執行
  • 能新建 HTML 檔案、用多游標與搜尋取代完成一份自己的作品，並在瀏覽器打開它
