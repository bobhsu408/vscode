個人名片網頁範本
================

card-template.html 是「實作：做一張自己的個人名片網頁」用的範本。

上課流程：
  1. 在 VS Code 用 File → Open Folder 打開解壓縮後的這個資料夾
  2. 把 card-template.html 整份內容複製，貼進你自己新建的 card.html
     （或者直接複製這個檔案、改檔名成 card.html 來改，都可以）
  3. 跟著課程網頁教的步驟，用 Ctrl+D / Alt+點擊 / Ctrl+H 改成自己的版本
  4. 存檔後用瀏覽器打開，看看成果

不需要網路、不需要安裝任何東西。
